# Screens Inventory: Todoist Pro

Catalogues each distinct screen or panel observed in Todoist's public documentation.
Each entry notes: screen name, purpose, key UI elements, and evidence source.

---

## 1. Inbox

**Purpose:** Default landing screen; collects tasks not assigned to a project.
**Key elements:**
- Task list with add-task input at bottom
- Each task row: checkbox, content, due date chip, priority flag, label tags, comment count, assignee avatar
- Section dividers (if sections added)
- Display menu (layout, sorting, grouping, task coloring)
- Three-dot menu per task (edit, move, duplicate, copy link, delete)

**Evidence:** Help Center - "What's the difference between the Inbox and a project?" [observed]
Source: https://todoist.com/help/todoist/features/whats-the-difference-between-the-inbox-and-a-project-d6dSLqAM, accessed 2026-10-11

---

## 2. Today View

**Purpose:** Aggregates all tasks due today across all projects.
**Key elements:**
- Overdue tasks section (collapsed or expanded)
- Today's tasks grouped by project or time
- Add task input
- Display options (sort, group, layout)

**Evidence:** Features page mentions "Today: focuses on tasks due that day" [observed]
Source: https://todoist.com/features, accessed 2026-10-11

---

## 3. Upcoming View

**Purpose:** Multi-day schedule for planning ahead; shows tasks by date.
**Key elements:**
- Day-by-day timeline (scrollable)
- Drag-and-drop rescheduling between days
- "No date" panel for undated tasks
- Calendar layout option (Week, 3-day, Month) [Pro]
- Time-blocking via drag on calendar

**Evidence:** Features page: "A schedule view for planning the week or month, with drag-and-drop rescheduling" [observed]
Source: https://todoist.com/features, accessed 2026-10-11

---

## 4. Project View (List Layout)

**Purpose:** Shows all tasks within a single project in list form.
**Key elements:**
- Project title and description
- Sections as collapsible groups
- Task rows with all metadata (due, priority, labels, assignee)
- Add task input per section
- Display menu: sort (date, priority, name, assignee), group (date, priority, label, section), show completed tasks toggle
- Share button, three-dot project menu (edit, duplicate, archive, delete, export as template)

**Evidence:** Help Center - "Use the list layout in Todoist" [observed]
Source: https://todoist.com/help/todoist/features/use-the-list-layout-in-todoist-AMAhHMVRH, accessed 2026-10-11

## 5. Project View (Board Layout)

**Purpose:** Kanban-style board; columns represent sections.
**Key elements:**
- Columns per section, with section headers
- Task cards within columns (draggable between columns)
- Add task button per column
- Display menu with board-specific options

**Evidence:** Help Center - "Use the board layout in Todoist" [observed]

## 6. Project View (Calendar Layout) [Pro]

**Purpose:** Tasks displayed on a calendar grid.
**Key elements:**
- Week, 3-day, or Month toggle (web/desktop)
- Agenda or Week view (mobile)
- Task blocks showing duration
- Drag-and-drop to reschedule
- "No date" drawer for undated tasks
- Deadline chips on tasks
- Task coloring (by priority, label, or project)
- No manual sort; uses default ordering

**Evidence:** Help Center - "Use the calendar layout in Todoist" [observed]
Source: https://todoist.com/help/todoist/features/use-the-calendar-layout-in-todoist-lPHRQTu0o, accessed 2026-10-11

## 7. Task Detail View

**Purpose:** Full task editor/viewer opened from any task row.
**Key elements:**
- Task name (editable, supports markdown)
- Description field (editable, markdown + links)
- Due date picker with natural language input
- Deadline picker [Pro]
- Priority selector (p1-p4, color-coded flags)
- Label picker (% prefix or browse)
- Reminder picker (date/time, before-task, recurring) [Pro for multiple]
- Duration picker [Pro]
- Project/section selector
- Assignee selector (in shared projects)
- Subtask list with add subtask input
- Comments section (text, file attachment, audio recording)
- Three-dot menu (duplicate, copy link, print, delete)
- Activity log for the task

**Evidence:** Help Center - "Use the task view to manage tasks in Todoist" and "Introduction to tasks" [observed]
Source: https://todoist.com/help/todoist/features/introduction-to-tasks-080OAXric, accessed 2026-10-11

## 8. Quick Add Modal

**Purpose:** Fast task creation from anywhere via keyboard shortcut (Q) or global shortcut.
**Key elements:**
- Single text input with natural language parsing
- Inline chips appearing as dates, labels, priorities, projects are detected
- Smart date recognition (toggleable)
- Reminder shortcut (`!30m`, `!every 5pm`)
- Project/section selector
- Priority, label, reminder, duration, deadline pickers below input
- Customizable defaults

**Evidence:** Help Center - "Use Task Quick Add in Todoist" and "Customize Quick Add in Todoist" [observed]
Source: https://todoist.com/help/todoist/features/use-task-quick-add-in-todoist-va4Lhpzz, accessed 2026-10-11

**Purpose:** Primary navigation; persistent on desktop, drawer/tab on mobile.
**Key elements:**

- Favorites section (pinned projects, labels, filters)
- Projects list (hierarchical with sub-projects, collapsible)
- Team section [Business]
- Add project button
- Search (Cmd/Ctrl+K)
- Settings access via avatar
- Task count badges (toggleable)

**Evidence:** Help Center - "Customize the sidebar and navigation menu" [observed]
